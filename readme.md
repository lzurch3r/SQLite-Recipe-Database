# SQLite/Python Recipe Database

A program written in Python that allows the user to add, delete, and display recipes from an SQLite database.

## Instructions for Build and Use

Steps to build and/or run the software:

1. You must have Python installed.
2. Navigate to the folder containing recipes.py
3. Right-click the folder and choose "Open in Terminal"
4. On Windows, run the following command: "python recipes.py"

Instructions for using the software:

1. From the menu, choose an option by typing the corresponding number and pressing "Enter".
2. Under option 1, type information for a recipe such as a title, a nationality, a tag, prep time, cook time, and serving amount.
3. (Option 2 is WIP)
4. Under option 3, the user can enter a number to delete the corresponding recipe from the list.
5. Under option 4, the user can choose to display all the recipes in the list or just one.
6. To exit the program naturally, choose option 5.
